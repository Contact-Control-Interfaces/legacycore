# Contact CI Library

This project houses the native C and C++ libraries.

If you're building this package from source or developing new features, see [BUILDING.md](BUILDING.md) (only available internally).

These libraries are meant to be consumed via a nuget or NPM package, so as to better maintain version compatability.

Otherwise, see [contactci.h](ccic%2Finclude%2Fcontactci.h) or [MaestroSessionManager.cs](CoreConductor%2FCoreConductor%2FMaestroSessionManager.cs) to understand how to use this.
